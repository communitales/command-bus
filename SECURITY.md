# Security policy

## Supported versions

The latest release is the recommended version. The maintainers have not published a security support schedule for older
releases; please ask them before relying on security fixes for an older version.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. If private vulnerability reporting is enabled,
use [GitHub's private reporting form](https://github.com/communitales/command-bus/security/advisories/new). Otherwise, contact
the maintainers privately through the contact information on [communitales.com](https://www.communitales.com/).

Include the affected version, a description of the impact, and steps to reproduce the issue. Please allow the
maintainers time to investigate and coordinate a fix before public disclosure.
